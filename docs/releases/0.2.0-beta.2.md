# Windows Diagnostics Toolkit v0.2.0-beta.2

This prerelease fixes collection reliability and source classification in Time
Sync Diagnostics and Performance Snapshot. It supports Windows PowerShell 5.1
and PowerShell 7 without third-party runtime dependencies.

## Fixed

- Added an internal 10-second process deadline to each standalone `w32tm`
  query. Concurrent bounded stream capture prevents stdout/stderr pressure from
  blocking collection. Separate cleanup and drain attempts retain partial output
  and report timeout, read, inherited-handle, and cleanup uncertainty explicitly.
- Recognized local-clock status across display languages through paired runtime
  reference ID and clock-token evidence. Exact English names remain a fallback;
  ordinary NTP servers, domain names, and virtualization time providers are not
  matched through broad text fragments. Missing or incomplete query evidence
  remains unavailable context.
- Kept a successful empty pagefile-usage query separate from a provider failure.
  Empty runtime records produce neutral, indeterminate context with no invented
  zero metrics or claim that a pagefile was intentionally disabled. Actual query
  failures and invalid allocation still produce availability warnings.
- Expanded regression coverage for simultaneous stream pressure, continuous
  output with timeout, inherited handles, faulted and cancelled reads, failed
  cleanup, localized time evidence, pagefile rendering, and finding summaries.
- Updated the fixed-release bootstrap and public documentation to
  `v0.2.0-beta.2`. Earlier release packages are unchanged.

## Limits and compatibility

The ordinary CLI, standalone launchers, snapshot schema version 1, offline
comparison, and incident workflows retain their existing contracts. Windows
process-provider delays can extend elapsed time beyond the query deadline and
its cleanup/drain budgets. A cleanup warning does not claim verified process
termination.

Local-clock detection depends on complete runtime evidence or the exact known
English names; unknown source text is retained without a synchronization-health
verdict. An empty runtime pagefile inventory does not establish configuration
intent. Missing data remains a limit on the assessment.

This remains a beta. No automatic remediation, Windows configuration changes,
telemetry, or report upload was added.
