# Windows Diagnostics Toolkit v0.2.0-beta.3

This prerelease improves report accuracy, makes partial collection visible and
verifies published release assets on repeat runs.

## Diagnostics and reports

- Reports flag incomplete module output even when the process exits successfully.
  The interactive terminal interface shows collection completeness and uses
  masked paths on the results screen when Privacy Mode is enabled.
- Crash diagnostics preserve separate event records that occur close together and
  flag uncertain duplicates. Offline snapshot comparisons check the query
  coverage of every contributing source, regardless of observation order.
- Network diagnostics check IPv4 and IPv6 gateways and flag the limits of the
  IPv4-only route fallback. Missing memory and storage values stay unknown.
  BitLocker reports per-volume query errors and paused conversion states.
- The interactive interface rejects output paths from non-filesystem providers.

## Release and compatibility

- The ZIP includes the concise README, updated usage guide and report example.
- Release automation verifies the published ZIP and checksum, including on
  repeat runs for an existing release.
- Windows PowerShell 5.1 and PowerShell 7 remain supported. The CLI switches,
  module exit-code contract and snapshot schema version 1 are unchanged.

See the [release verification guide](../release-verification.md) for
automated coverage and the manual Windows client checklist.
